# DeskTrack Windows Agent (apps only)

- **Chrome / My desk** — webcam, face, presence  
- **This agent** — which desktop app is focused  

## Install once

1. Python 3 with PATH  
2. Run `Install-DeskTrack-Agent.bat`  
3. Enroll face on the website, Clock in, keep My desk open  

Website **Reset login** does not break the agent (server keeps a separate agent password).

The agent self-updates from GitHub on start.
